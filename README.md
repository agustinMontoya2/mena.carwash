# MENA Car Wash

> Limpieza que se nota, calidad que dura.

A premium landing page for **MENA Car Wash**. Built with a dark, showroom aesthetic, it showcases services, live pricing, gallery, customer reviews, and direct booking via WhatsApp and Instagram.

## Tech stack

- **React 19** — UI framework
- **Vite 8** — build tool and dev server
- **TypeScript** — type-safe code
- **Tailwind CSS v4** — utility-first styling

## Getting started

```bash
pnpm install     # install dependencies
pnpm dev         # start dev server (http://localhost:5173)
pnpm build       # production build to dist/
pnpm preview     # preview the production build
pnpm format      # format code with oxfmt
```
